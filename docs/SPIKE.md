# SPIKE — Vovozinha local AI stack

## Phase now: **text only** + **LLM-only stories** (`FeatureFlags.graphicsEnabled = false`)

Focus: **10-page narrative generated by an on-device LLM** (no pre-written page templates in production).

| Stage | Current | Notes |
|-------|---------|--------|
| Story text | **`FoundationModelsStoryPlanner`** | Apple on-device LLM + `@Generable` 10 paragraphs. Fails if FM unavailable (no template fallback). |
| Character | Description + optional photo (text use) | Vision/FM multimodal later (`MockCharacterAnalyzer` for now) |
| Illustrations | **Disabled** | Future local image pack; `ProceduralKidsIllustrator` kept offline until then |
| TTS / PDF / library | On | Text-first reader & PDF; story language persisted |

Scene-beat labels live in **`StorySceneTags`** (not a story planner).

## From Grok analysis (native iOS)

- **Narrative text:** Apple Foundation Models (on-device) are capable.
- **High-quality images:** **not** fully local via Apple — need **own** image models (Mobile-O, SD-Turbo, etc.) or Apple cloud Image Playground (rejected for local-only product).

## Next phase (graphics)

1. Bring **own** local image gen pack (diffusion / unified mobile model).
2. Condition on reference photo + per-page `imagePrompt` already stored on `StoryPage`.
3. Flip `FeatureFlags.graphicsEnabled = true`.

## Constraints

- Local-only inference (no cloud for generate).
- iPhone 15+ floor; **A16** needs optional **local LLM pack** (not shipped yet).
- Kids safety filter; no social features.
